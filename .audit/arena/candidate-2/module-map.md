## 4. Screening Against `design-red-flags.md`

| Red Flag | How Candidate 2 Eliminates It Structurally |
|---|---|
| **Shallow module** | Callers invoke 4 deep interfaces (`EpisodeSubtitleSession`, `SidecarReconciler`, `SubtitleRankingPolicy`, `LiveSubtitleSyncSession`) with ~10 methods total, hiding 9-FPS rational `alass` DP, 16 kHz FFT/biquad VAD, ISO-BMFF/HLS PTS anchoring, `nextlib` JNI decoding, `TextRenderer` cursor invariants, and 1-to-1 bol-chal localization. |
| **Information leakage** | Wire headers (`X-StreamPlay-*`), `SidecarManifestV2` JSON fields, Google/LLM HTTP schemas, and `moov`/`stbl` boxes stay private inside `ProvenanceCodec`, `SidecarManifestStore`, `BolChalTransport`, and `SparseMediaAudioProber`. Public APIs pass domain types (`ProvenanceIdentity`, `SubtitleTimeWarp`, `SpeechActivityTimeline`). |
| **Temporal decomposition** | Modules own domain invariants across time rather than execution stages: `ProvenanceCodec` owns both encode and decode; `SubtitleTimeWarp` owns both offline VTT baking and live `WarpedSubtitle` projection; `SidecarReconciler` owns both initial download save and offline heal reconciliation. |
| **Pass-through method** | ~2,500 lines of duplicated `SuperStream` wrappers are deleted in favor of direct `shared/subtitles` compilation; `AppContextUtils.sortSubs` delegates directly to `SubtitleRankingPolicy` without intermediate adapter layers. |
| **Split ownership** | Ranking has 1 owner (`SubtitleRankingPolicy`), provenance has 1 owner (`ProvenanceCodec`), episode state has 1 per-request owner (`EpisodeSubtitleSession` — zero singleton maps), and subtitle offset has 1 per-player owner (`LiveSubtitleWarpController` — zero `CustomDecoder.subtitleOffset` static). |
| **Two ways to do one task** | Old `findBestConstantOffset`, `isBrokenSmtUrdu`, `scoreUrduSubtitleNaturalness`, `splitTranslatedUrduProportionally`, `splitReadableLines`, and `publishToSubtitleCatCdn` are deleted in the same change rather than kept alongside the new core. |
| **Importable internals** | `LatinEnglishText`, `ContentSha256`, `SubtitleTimeWarp.PiecewiseLinear`, and `VerifiedSubtitleCandidate.Admitted` constructors are `private`/`internal`, making unvalidated admission, non-monotonic warps, or Nastaliq-contaminated NMT inputs unconstructible outside their boundary gates. |
| **Hand-synced list** | `:StreamPlay` and `:SuperStream` compile the exact same `shared/subtitles/src/main/kotlin` files; cross-repo enum parity between `cloudstream-extensions-phisher` and `cloudstream` is locked by `CrossRepoProvenanceContractTest`. |
