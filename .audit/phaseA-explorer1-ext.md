### Boundaries
- **Extension <-> Host App (`cloudstream`) Contract**:
  - Cross-classloader mode sync uses `System.getProperty("cloudstream.subtitle.mode")` (`"default"` | `"urdu"`) + SharedPreferences `"cloudstream_subtitle_mode_prefs"` and host `"subtitles_auto_select"` (`"en"` | `"ur"`) ([UrduSubtitleEngine.kt:278-371](/home/mahmood/.t3/worktrees/cloudstream-extensions-phisher/feat-urdu-bolchal-audio-999f345cb2d84bbf/StreamPlay/src/main/kotlin/com/Phisher98/UrduSubtitleEngine.kt:278)).
  - Every emitted `SubtitleFile` carries `headers["X-StreamPlay-Source"]` and (for Urdu) a formatted `lang` badge (`Urdu [SubDL]`, `Urdu [Neural AI]`, etc.) plus a local `file:///.../cs_urdu_*.srt` URI (never containing `"superstream"` in its filename because the host's `DownloadSubtitlePolicy` bans `"superstream"` URLs — see [SuperStreamUrduSubtitleTest.kt:323-331](/home/mahmood/.t3/worktrees/cloudstream-extensions-phisher/feat-urdu-bolchal-audio-999f345cb2d84bbf/SuperStream/src/test/kotlin/com/phisher98/SuperStreamUrduSubtitleTest.kt:323)).
  - **Zero Video-Stream Feedback Into Extension Subtitle Selection**: `loadLinks` emits `ExtractorLink`s and `SubtitleFile`s asynchronously in parallel; the extension never knows which video `ExtractorLink` (or actual HLS/MP4 duration/FPS) ExoPlayer or `DownloadManager` ultimately selects, nor can it inspect audio/video media timestamps to detect or correct constant offset or FPS drift.
